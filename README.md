# 📊 Excel Sales Performance Dashboard

This project is an interactive Sales Dashboard built entirely in Microsoft Excel to analyze retail sales data and visualize key business metrics.

### 🔍 Project Overview
I used a raw dataset of 500+ transactions and transformed it into an automated dashboard that helps track revenue, top-selling products, and regional performance. The goal was to reduce manual reporting and make data-driven decisions easier.

### ✨ Key Features
- **Data Cleaning:** Used Remove Duplicates, Text-to-Columns, and TRIM
- **Data Analysis:** Pivot Tables to summarize sales by Month, Product & Region
- **Automation:** IF, SUMIF, AVERAGEIF for auto-calculations
- **Visualization:** Dynamic Bar Chart, Line Chart, Donut Chart + Slicers
- **Formatting:** Conditional Formatting to highlight low sales and top performers

### 🛠️ Tools & Formulas Used
`Microsoft Excel | VLOOKUP | Pivot Table | Slicers | Conditional Formatting | SUMIF | Charts`
